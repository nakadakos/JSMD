# JSMD – Just a Simple Mod Downloader

JSMD is a fast, minimal, and lightweight Fabric mod downloader for Minecraft. It allows users to search, select, and install mods directly from Modrinth with a clean and simple interface.

---

## Features

* Search Fabric mods from Modrinth
* One-click download and install
* Multi-threaded fast downloads
* Lightweight and easy to use

---

## Download

Download the latest version from the Releases page:

https://github.com/YOUR_USERNAME/JSMD/releases

Download the file:

JDSM_Setup.exe

Run the installer and launch JSMD.

---

## How it works

1. Open JSMD
2. Select your Minecraft version
3. Search for mods
4. Select the mods you want
5. Click Download Mods

Mods will be installed automatically.
